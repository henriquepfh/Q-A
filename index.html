⚙️ Configure seu Google Client ID Para usar o login com Google, siga estes passos:
  1. Abra o arquivo HTML num editor de texto
  2. Encontre a linha const GOOGLE_CLIENT_ID = ''
  3. Acesse console.cloud.google.com, crie um projeto, vá em APIs & Services → Credentials → Create OAuth 2.0 Client ID
  4. Em Authorized JavaScript origins, coloque a URL onde o arquivo está hospedado
  5. Cole o Client ID gerado no lugar de '' no arquivo
  6. Hospede o arquivo em HTTPS (ex: GitHub Pages, Netlify)
